# OpenCart E-Commerce Platform - Manual QA Testing Project

## 🎯 Project Objective
This repository contains the complete Software Testing Life Cycle (STLC) documentation for the OpenCart open-source e-commerce platform. I created this project to demonstrate my ability to design, document, and execute industry-standard manual testing artifacts from scratch.

## 📝 Project Scope
The testing scope focuses on the core functional workflows of an e-commerce application, ensuring a seamless user journey from product discovery to checkout. 
*(Note: Update this list based on the actual modules you decided to test)*
* **User Authentication:** Registration, Login, and Password Reset.
* **Product Navigation:** Search functionality, category filtering, and product details.
* **Cart Management:** Adding/removing items, updating quantities, and applying coupons.
* **Checkout Workflow:** Guest vs. registered user checkout, payment gateway simulation, and order confirmation.

## 📂 Repository Structure & Deliverables

This project follows a structured STLC approach, with documentation divided into the following phases:

* **`/1_Test_Plan`**
  * Contains the master **Test Plan** document detailing the project scope, test strategy, entry/exit criteria for all STLC phases, resource requirements, and risk mitigation strategies.
* **`/2_Test_Scenarios_and_Cases`**
  * Contains the **Test Scenarios** outlining high-level testing ideas.
  * Contains the detailed **Functional Test Cases** mapping steps to reproduce, expected results, and actual results.
* **`/3_Defect_Reports`**
  * Contains sample **Defect Reports** detailing identified bugs, priority/severity levels, and clear steps to reproduce with attached screenshots.
* **`/4_Test_Summary`**
  * Contains the **Test Closure / Summary Report** showcasing bugs by functional area, priority, and overall test execution metrics.
